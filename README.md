# Clinvag — Landing Page

Landing page desenvolvida para a **Clinvag - Clínica de Vacinação de Garanhuns**, localizada em Garanhuns, PE.

## 🖥️ Preview

> Acesse: [clinvag.netlify.app](https://clinvag.netlify.app) *(atualizar com o link real após deploy)*

---

## 🚀 Tecnologias

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- CSS Modules (por componente)
- Google Maps Embed API
- Google Fonts — Playfair Display + DM Sans

---

## 📁 Estrutura do projeto

```
src/
  components/
    Navbar.jsx / Navbar.css
    Hero.jsx / Hero.css
    Vacinas.jsx / Vacinas.css
    ComoFunciona.jsx / Comofunciona.css
    Contato.jsx / Contato.css
    Footer.jsx / Footer.css
  App.jsx
  App.css
  index.css
  main.jsx
```

---

## 📦 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/GilsonCataoDev/Clinvag.git

# Entre na pasta
cd Clinvag

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:5173` no navegador.

---

## 📄 Seções da página

- **Navbar** — navegação fixa com botão de agendamento
- **Hero** — apresentação da clínica com chamada para ação
- **Vacinas** — cards com as principais vacinas disponíveis
- **Como Funciona** — passo a passo do agendamento
- **Contato** — endereço, WhatsApp e mapa do Google Maps
- **Footer** — informações institucionais
